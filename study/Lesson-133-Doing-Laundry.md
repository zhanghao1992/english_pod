# Lesson 133 · Doing Laundry（洗衣服）

> **等级**：Intermediate（中级）　**编号**：C0133　**场景**：Daily Life 日常生活（在家学用洗衣机）
> **学习目标**：学会用英语讲解洗衣流程、处理污渍和操作烘干机，掌握 6 个高频表达：
> `go through` / `so-called` / `do the trick` / `all set` / `have sth dry cleaned` / `How do I get it out?`

---

## 一、对话原文（Dialogue）

**A = 懂洗衣、在一旁指导的人（室友/家人）　B = 第一次学洗衣服的人**

- **A**: Ok, let's go through this one more time. I don't want anymore ruined or dyed blouses!
- **B**: I know, I know. OK, so I have to separate the colors from the whites and put them in this strange looking contraption so called washing machine.
- **A**: Right. You have to turn it on and program it depending on what type of clothes you are washing. For example for delicates, you should set a shorter washing cycle. Also, be sure to use fabric softener and this detergent when washing.
- **B**: So complicated! Ok, what about this red wine stain? How do I get it out?
- **A**: Since this is a white t-shirt, you can just pour a little bit of bleach on it and it will do the trick.
- **B**: Cool. Then I can just throw everything in the dryer for an hour and it's all set right?
- **A**: No! Since you are washing delicates and cotton, you should set the dryer to medium heat and for twenty minutes.
- **B**: You know what? I'll just have everything dry cleaned.

> 勘误：PDF 中 B 谈论烘干机的那句写作 *its all set right?*，规范英文应为 *it's all set, right?*；*so called* 规范写法常加连字符 *so-called*。以下讲解按规范形式处理。

## 三、核心生词与短语（Key Vocabulary）

### 1. dye /daɪ/ 　动词（过去式/过去分词 dyed /daɪd/）
- **意思**：给……染色、染色（头发、衣物等）。
- **用法/搭配**：
  - 及物动词：*dye sth + 颜色*（*dye the dress blue* 把裙子染成蓝色）；*dye one's hair* 染头发。
  - 对话中 *dyed blouses* 是过去分词当形容词用，指"被染了色的衬衫"。
- **例句**：
  - *Women dye their hair at the beauty salon.*（女士们在美发店染头发。——节目讲解例句）
  - *All my white shirts were dyed pink.*（我所有白衬衫都被染成了粉色。）
- **勘误/辨析**：PDF 词性栏标作 "principle verb, past simple"，其中 principle 系模板笔误（应为 principal），且词头 dye 是动词原形，并非过去式。另注意 *dye*（染色）与 *die*（死亡）同音 /daɪ/，拼写不同；现在分词是 *dyeing*，不是 dying。

### 2. contraption /kənˈtræpʃn/ 　名词（可数）
- **意思**：（样子古怪、构造复杂的）装置、玩意儿，常带调侃或不以为然的语气。
- **用法/搭配**：
  - 常说 *a strange/weird-looking contraption*（一个怪模怪样的装置），比直接说 machine 更生动、更口语。
  - 对话中 B 故意用这个词，表示他根本不把洗衣机当回事、嫌它难操作。
- **例句**：*I don't know how this contraption works.*（我不知道这玩意儿怎么用。）

### 3. do the trick /duː ðə trɪk/ 　动词短语
- **意思**：管用、奏效、解决问题（= accomplish the desired task / solve the problem）。
- **用法/搭配**：
  - 主语通常是"某个办法/东西"：*This should do the trick.*（这招应该管用。）
  - 时态随主语变化：*it did the trick*（过去时）；trick 在这里不是"骗局"，而是"窍门、妙招"。
- **例句**：
  - *Put some ointment on it and that should do the trick.*（抹点药膏，应该就好了。——节目讲解例句）
  - *A cup of coffee will do the trick.*（喝杯咖啡就管用了。）

### 4. all set /ɔːl set/ 　短语
- **意思**：准备好了、一切就绪（= ready, prepared）；也可表示"做完了、完事了"。
- **用法/搭配**：
  - *be all set (for/to do sth)*：*We're all set to go.*（我们准备好可以出发了。）
  - 口语确认：*Are we all set?*（咱们完事了吧？/ 都准备好了吗？）
- **例句**：
  - *We're all set to go on vacation.*（我们度假的东西都备齐了。——节目讲解例句）
  - *After a meeting, you can say "Are we all set here?"*（开完会可以问："这儿的事都结束了吧？"）

### 5. dry clean /ˌdraɪ ˈkliːn/ 　动词（过去式/过去分词 dry cleaned）
- **意思**：干洗，即用化学药剂而不用水洗衣服（*a way to clean clothes without water*）。
- **用法/搭配**：
  - 最常用使役结构 **have sth dry cleaned**：让别人把某物干洗（自己不动手）。
  - 名词写法常合为一个词 *dry-cleaning*：*a dry cleaner's*（干洗店）。
- **例句**：*I'll just have everything dry cleaned.*（我干脆把所有衣服都送去干洗。——对话原句）
- **勘误**：PDF 词性栏同样标作 "principle verb, past simple"，词头 *dry clean* 实为动词原形；对话中出现的是使役结构里的过去分词 *dry cleaned*。

### 6. go through /ɡəʊ θruː/ 　动词短语（补充）
- **意思**：把（流程、内容）完整过一遍、演练/复习一遍；不是字面上的"穿过"。
- **用法/搭配**：
  - 用于多步骤的事情：*Let's go through this one more time.*（咱们再走一遍流程。）
  - 学习场景：*go through the chapter*（把这一章复习一遍）；近义词组 *go over*（过一遍细节）。
- **例句**：
  - *I want to go through chapter five again before the exam tomorrow.*（明天考试前我想把第五章再过一遍。——官方例句）
  - *I went through my contract and it says I am entitled to 15 vacation days a year.*（我把合同仔细看了一遍，上面说我每年有 15 天年假。——官方例句）

### 7. so-called /ˌsəʊ ˈkɔːld/ 　形容词（补充）
- **意思**：所谓的；加在名词前表示"名不副实"，常带讽刺、怀疑语气。
- **用法/搭配**：
  - *one's so-called + 名词*：*her so-called boyfriend*（她那个"所谓的男朋友"）、*my so-called friends*（我那些所谓的朋友）。
  - 对话里 B 用 *so called washing machine* 吐槽：这东西真配不上"洗衣机"这个名字。
- **例句**：*Her so-called boyfriend never helps her.*（她那个所谓的男朋友从来不肯帮她。——节目讲解例句）
- **语用提醒**：当面说别人 *my so-called friend* 是开玩笑还是讽刺要拿捏好，认真场合用会得罪人。

### 8. stain /steɪn/ 　名词（补充，节目 Vocabulary Preview 词条）
- **意思**：污渍（食物、酒、草汁等留在衣物、地毯上洗不掉的颜色）；也可作动词"弄脏、染色"。
- **用法/搭配**：
  - *a wine/coffee/grass stain*（红酒/咖啡/草渍）；*remove/get out a stain*（去掉污渍）。
  - *stained teeth*（被熏黄的牙齿）；*stainless steel*（不锈钢，字面"不沾污的钢"）。
- **例句**：*What about this red wine stain? How do I get it out?*（这块红酒渍怎么办？我怎么弄掉它？——对话原句）

## 四、重点句型（Sentence Patterns）

1. **Let's go through this one more time.**
   "咱们再把这个过一遍。"——教人做事、带新人、复习功课时的万能开场，*go through* 强调"完整走一遍多步骤流程"。
   仿写：*Let's go through the pronunciation one more time.*（咱们把发音再过一遍。）

2. **You have to / Be sure to … when washing.**
   讲解操作步骤的指令句型：*You have to turn it on and program it…* / *Be sure to use fabric softener…*。*be sure to do* 比 *you must* 语气友好，适合写说明书和口头指导。
   仿写：*Be sure to separate the colors when washing clothes.*（洗衣服时一定要把彩色和白色分开。）

3. **How do I get it out?**
   "我怎么把它弄掉？"——问如何去除污渍的地道说法，*get out* 在这里 = remove；不能说 *How to wash it?*
   仿写：*There's a coffee stain on my shirt. How do I get it out?*（我衬衫上有咖啡渍，怎么才能洗掉？）

4. **It will do the trick.**
   "这招就能解决问题。"——推荐简单有效的解决办法时用，主语也可换 *this/that should*。
   仿写：*Try this stain remover — it should do the trick.*（试试这款去渍剂，应该管用。）

5. **Then I can just …, right?**
   "那我只要……就行了，对吧？"——*Then I can just…* 用来确认自以为省事的做法，句尾 *right?* 征求确认；对话里 B 正是因此被纠正。
   仿写：*Then I can just leave it here, right?*（那我把它放这儿就行了，对吧？）

6. **I'll just have everything dry cleaned.**
   "我干脆把所有衣服都干洗算了。"——使役结构 **have sth done**：让别人为自己做某事，如 *have my hair cut*（理发）、*have the car repaired*（修车）。
   仿写：*I'll have this suit dry cleaned before the interview.*（面试前我要把这套西装送去干洗。）

## 六、讲解拓展（来自节目讲解）

- **go through 的画面感**：主持人强调它不是"穿过物体"，而是"把有多个步骤的流程重新捋一遍"——回家开门的一系列动作、复习课本第五章、逐条看合同，都可以用；搭配名词 *go over the details* 同样表示"把细节过一遍"。
- **so-called 是最简单的讽刺句型**：在任何名词前加上 *so-called* 就表示"配不上这个名字"：*so-called boyfriend / friends / job*。主持人还提到 90 年代美剧 *My So-Called Life*（《我所谓的生活》），片名就是这种自嘲口吻。但玩笑分寸要小心，认真场合会让对方生气。
- **do the trick 里的 trick**：狗会表演 tricks（把戏），但 *do the trick* 表示"这招奏效、问题解决"。药膏止痒、咖啡提神、漂白剂去渍，凡是"一个小东西解决问题"的场景都能用，口语里极其高频。
- **all set 的两层意思**：一是"准备就绪"（行李护照都拿好，*We're all set to go on vacation*），二是"事情结束了"（开完会问 *Are we all set here?*，意思是可以散会了吗）。
- **洗衣相关词汇链（Language Takeaway）**：*delicates*（娇贵衣物，名词复数，多指内衣等易坏衣物）→ *fabric softener*（柔顺剂，fabric 指棉、丝、尼龙等织物）→ *detergent*（洗衣液/洗衣粉，洗衣专用，洗手洗盘子的才叫 soap）→ *bleach*（漂白剂，味冲、只用于白衣；把头发漂白说 *bleach one's hair*，染发才说 *dye*）。
- **洗衣事故文化谈**：主持人分享：热水会让衣服 *colors bleed*（掉色串色），所以他在大学一律用冷水；三台新毛衣被烘成了婴儿尺寸（*shrink* 缩水）；衣服忘在洗衣机里一夜会发霉变味（*moldy*），只能重洗。另外国外常见 *laundromat*（投币自助洗衣店），是很多美剧里的经典场景。

## 八、学习建议（CET-4 水平）

1. **精听 + 影子跟读**：本段是"指导操作"类对话的范本（祈使句、步骤连接词密集）。先盲听两遍抓流程，再看着原文跟读，重点模仿 *do the trick*、*all set, right?* 的语调和 *so-called* 的讽刺重音。
2. **流程复述训练**：看着中文译文，用英语把洗衣五步复述出来：*separate → turn on/program → detergent & softener → bleach for stains → dryer medium heat 20 min*，强迫自己使用 *first / then / also / since* 等连接词。
3. **造句输出**：用 `have sth done` 造 3 个生活句（理发、修车、干洗），再用 `do the trick` 和 `all set` 各造 2 句；这些使役和口语短语是四级写作、口语的提分点。
4. **主题词汇成组记**：把 *washing machine / dryer / detergent / fabric softener / bleach / stain / laundromat / iron / clothes hamper* 画成一张"洗衣房词汇图"，第 1、3、7 天各复习一次，配合听力场景记忆最牢。
