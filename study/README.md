## 使用建议

1. 先盲听 1–2 遍音频，再对照「对话原文」查缺；
2. 精读「核心生词与短语」和「重点句型」，跟着例句大声朗读；
3. 遮住英文看中文译文做复述，最后做「小练习」自测；
4. 每课复习节奏：当天 → 第 2 天 → 第 4 天 → 一周后。
